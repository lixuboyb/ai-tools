# 视频截图工具

一个功能强大的视频播放和截图工具，支持视频播放、区域裁剪、倍速播放和多格式图片保存。

## 功能特点

- 🎬 **视频播放**：支持多种常见视频格式（MP4、AVI、MOV、MKV、WMV、FLV等）
- 📷 **帧保存**：实时保存当前视频帧为图片
- ✂️ **区域裁剪**：通过鼠标拖动选择视频中的特定区域进行裁剪
- ⚡ **倍速播放**：支持 0.25x 到 4x 的播放速度调节
- 🎯 **进度控制**：精确的进度条拖动和时间显示
- 💾 **多格式保存**：支持 PNG、JPG、JPEG、BMP、TIFF 等多种图片格式
- 🎨 **自定义命名**：可自定义保存图片的文件名前缀
- 🖥️ **现代化界面**：采用深色主题，视觉体验舒适

## 安装方法

### 环境要求

- Python 3.7 或更高版本
- FFmpeg（用于视频解码）

### 依赖安装

使用 pip 安装所需依赖：

```bash
pip install opencv-python PySide6 numpy
```

### FFmpeg 配置

确保系统已安装 FFmpeg 并添加到环境变量中。可以通过以下命令验证：

```bash
ffmpeg -version
```

如果未安装，请从 [FFmpeg 官网](https://ffmpeg.org/download.html) 下载并配置。

## 使用方法

### 启动程序

在命令行中运行：

```bash
python 视频截图工具.py
```

### 基本操作

#### 1. 打开视频

- 点击工具栏的 **"📁 打开视频"** 按钮
- 或使用快捷键：Ctrl+O（如已配置）
- 支持的视频格式：MP4、AVI、MOV、MKV、WMV、FLV

#### 2. 播放控制

- **播放/暂停**：点击 "▶ 播放" 或 "⏸ 暂停" 按钮
- **快捷键**：空格键 切换播放/暂停

#### 3. 调节播放速度

- 在工具栏的下拉框中选择播放速度
- 可选速度：0.25x、0.5x、0.75x、1x、1.25x、1.5x、2x、3x、4x

#### 4. 区域裁剪

- 在视频画面上按住鼠标左键拖动，绘制红色虚线框
- 松开鼠标后，裁剪区域生效
- 裁剪分辨率会实时显示在界面上
- 按下 **Esc 键** 或点击 "🚫 取消区域选择" 按钮可取消裁剪

#### 5. 保存当前帧

- 点击 **"📷 保存当前帧"** 按钮
- 或按 **Q 键** 快捷保存
- 保存的图片格式可在工具栏下拉框中选择（PNG/JPG/JPEG/BMP/TIFF）

#### 6. 自定义保存设置

**更改保存文件夹**：
- 点击 "📁 选择保存文件夹" 按钮
- 选择图片保存的目标目录

**打开保存文件夹**：
- 点击工具栏的 "📂 打开保存文件夹" 按钮
- 快速查看已保存的图片

**自定义文件名**：
- 在工具栏输入框中输入文件名前缀
- 保存时会自动追加序号（如：frame_000.png、frame_001.png...）

#### 7. 进度控制

- 拖动进度条可快速跳转到视频的任意位置
- 拖动过程中会实时预览对应帧
- 当前时间和总时长显示在进度条两侧

## 快捷键

| 快捷键 | 功能 |
|--------|------|
| 空格键 | 播放/暂停 |
| Q | 保存当前帧 |
| Esc | 取消区域选择 |

## 默认设置

- **默认保存目录**：程序目录下的 `saved_frames` 文件夹
- **默认图片格式**：PNG
- **默认文件名前缀**：frame
- **默认播放速度**：1x

## 技术特性

- 使用 OpenCV 进行视频解码和帧处理
- 基于 PySide6 构建现代化 GUI 界面
- 支持异步视频帧数估算，避免界面卡顿
- 精确的进度控制和时间显示
- 智能的裁剪区域映射和缩放处理

## 注意事项

1. 确保系统已正确安装 FFmpeg
2. 大尺寸视频可能需要较长的加载时间
3. 保存 JPG 格式时使用 95% 质量以保证画质
4. 裁剪区域的最小尺寸限制为视频尺寸的 1%

## 常见问题

**Q: 无法打开视频文件？**
A: 请检查 FFmpeg 是否正确安装并添加到环境变量中。

**Q: 保存的图片质量不佳？**
A: 尝试使用 PNG 格式保存以获得无损画质。

**Q: 程序启动失败？**
A: 确保已安装所有依赖包（opencv-python、PySide6、numpy）。
